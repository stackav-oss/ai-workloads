# ai-workloads

This repo contains different types of AI workloads to test and evaluate.

## Whisper

whisper contains evaluation script for the whisper model.

## Clip
clip contains evaluation scripts for clip, siglip1 and siglip2 models.

## Cosmos
Cosmos contains evaluation scripts for nvidia cosmos predict and tranfer models.

## LiDAR VAE
lidar_vae contains the LiDAR-only NuScenes VAE training workload.

## Mega-SAM
`mega_sam` contains the mega-sam workload
